R语言——ggplot2包

2026-07-12

R语言中绘图可以选取自带的基础绘图系统plot()，也可以选择ggplot2包。前者像“命令式”作画，一步步下达指令，在画布上添加元素；后者像“声明式”设计，基于“图形语法”，用“图层”叠加的方式构建图形。

基础内容

绘图模板如下：

ggplot(data = 数据集, mapping = aes(映射规则)) +
  geom_xxx(图层参数, stat = 统计变换, position = 位置调整) + # 几何图层
  scale_xxx(标度参数) + # 坐标轴/颜色/形状标度
  coord_xxx() + # 坐标系
  facet_xxx() + # 分面
  labs() + # 标题、坐标轴标签
  guides() + # 图例精细调整
  theme() # 全局美化主题
  • geom_xxx（绘图类型）:
geom_point()
散点图		 geom_smooth()
拟合曲线（线性 /loess 平滑，自带置信区间）		 geom_line()
折线图（x 轴数值从小到大排序）		 geom_path()
连线（从上到下的原始行顺序）
geom_boxplot()
箱线图（分组分布）		 geom_violin()
小提琴图		 geom_jitter()
抖动散点（解决点重叠）		 geom_histogram()
直方图（连续变量分布）
geom_density()
密度曲线		 geom_col()
柱状图（y数值作为柱子高度）		 geom_bar()
计数柱状图（统计 x 频数）		 geom_text()/geom_label()
文字标签
geom_errorbar()
误差棒		 geom_hline()/geom_vline()
水平 / 垂直参考线		 geom_ribbon()
画两条 y 曲线之间填充的带状区域		 geom_rug()
边缘地毯图(一种一维散点图)
  • stat 统计变换：geom 底层自带统计计算，可手动修改stat参数
stat="count" 计数（geom_bar 默认）
stat="identity" 直接使用原始 y 值（geom_col 默认）
stat="smooth" 拟合平滑曲线（geom_smooth）
stat="bin" 分箱统计（直方图）
  • position 位置调整：解决重叠
position = "identity" 默认，不偏移
position = "dodge" 分组并列柱状图
position = "stack" 堆叠柱状图
position = "fill" 百分比堆叠柱状
position = "jitter" 点抖动防重叠
  • scale标度：负责数据→视觉属性转换，同时生成坐标轴刻度、图例，命名规则为scale_视觉属性_类型
scale_x_continuous()/scale_y_continuous() 连续轴（对数trans="log10"、调整范围 limits）
scale_x_discrete() 分类 x 轴（修改标签、调整顺序）
scale_color_manual()/scale_fill_manual() 手动自定义颜色向量
scale_color_brewer() RColorBrewer 配色
scale_color_viridis_c() 连续渐变配色
scale_size()、scale_shape_manual() 大小 / 形状标度
  • coord 坐标系：
coord_cartesian() 默认直角坐标
coord_flip() xy 轴翻转，横向柱状图
coord_polar() 极坐标（饼图、雷达图）
coord_log10() 对数坐标轴
coord_fixed() 固定 xy 轴比例（等比例散点图）
  • Facet 分面（多子图）：按分类变量自动拆分图表，无需循环绘图
facet_wrap(~变量) 一维分面，自动换行
facet_grid(行变量 ~ 列变量) 二维网格分面
  • 主题系统美化：

1）内置完整主题：

theme_bw() 白底 + 浅灰色网格线，带黑色边框
theme_minimal() 无边框、浅细网格
theme_classic() 无网格，仅保留 XY 黑色轴线
theme_void() 完全空白，无坐标轴、无背景

panel.cor <- function(x, y, digits = 2, prefix = "", cex.cor, ...) {
  usr <- par("usr")
  on.exit(par(usr))
  par(usr = c(0, 1, 0, 1))
  r <- abs(cor(x, y, use = "complete.obs"))
  txt <- format(c(r, 0.123456789), digits = digits)[1]
  txt <- paste(prefix, txt, sep = "")
  if (missing(cex.cor)) cex.cor <- 0.8/strwidth(txt)
  text(0.5, 0.5, txt, cex =  cex.cor * (1 + r) / 2)
}

panel.hist <- function(x, ...) {
  usr <- par("usr")
  on.exit(par(usr))
  par(usr = c(usr[1:2], 0, 1.5) )
  h <- hist(x, plot = FALSE)
  breaks <- h$breaks
  nB <- length(breaks)
  y <- h$counts
  y <- y/max(y)
  rect(breaks[-nB], 0, breaks[-1], y, col = "white", ...)
}
